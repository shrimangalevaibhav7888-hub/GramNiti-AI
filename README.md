# GramNiti AI

### AI-Driven Hyper-Local Business and Financial Advisory for Rural Micro-Entrepreneurs

GramNiti AI is an AI-powered decision-support platform designed to help rural micro-entrepreneurs make better business and financial decisions.

## Key Features

- 🌾 Hyper-local business recommendations
- 💰 Financial planning and structuring
- 🏛️ Government scheme discovery
- 📊 Business feasibility analysis
- 📋 Personalized action plans
- 🌐 Multilingual rural-friendly interface
- 🤖 AI-assisted decision support

## Technology Stack

### Frontend
- React
- Vite
- JavaScript

### Backend
- Python
- FastAPI
- SQLAlchemy

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: SQLite / PostgreSQL compatible
